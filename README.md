# Zajęcia nr 1 — pierwsze kroki

Kurs: Projektowanie eksperymentów i analiza danych metodami sztucznej inteligencji.

Otwórz **`01_start.ipynb`** w GitHub Codespaces. Wybierz kernel Python z `.venv` i czytaj od góry. Cały kod jest gotowy. Własne odpowiedzi wpisujesz tekstem do komórek Markdown. Po uruchomieniu zobaczysz koszyk pięciu produktów, sumę **29,60 zł** i wykres.

Ten pakiet dotyczy jednego spotkania wprowadzającego. Pierwsze ćwiczenia z Copilotem będą na zajęciach nr 2, w osobnym notebooku.

## Pliki

- `01_start.ipynb` — jedyny notebook tej lekcji, z instrukcją obsługi środowiska.
- `zakupy.csv` — fikcyjne dane do obliczeń (5 wierszy, 3 kolumny).
- `zakupy.py` — gotowy skrypt do obejrzenia; nie trzeba go edytować ani uruchamiać na tym etapie.
- `SLOWNIK_DANYCH.md` — opis kolumn i wyniki kontrolne.
- `requirements.txt` — biblioteki instalowane na serwerze.
- `.devcontainer/devcontainer.json` — konfiguracja Codespaces z rozszerzeniem Rainbow CSV.
- `devcontainer.json` — identyczna, widoczna kopia do ręcznego dodawania konfiguracji na GitHub. Właściwa konfiguracja musi leżeć w `.devcontainer`.

Uruchomienie tworzy `wykres_zakupow.png` i `potwierdzenie_startu.txt` w głównym folderze. Zapisz i pobierz oba pliki oraz uzupełniony notebook. Zatrzymaj środowisko przez [github.com/codespaces](https://github.com/codespaces).

Szczegóły rejestracji i zadania dla nieobecnych znajdują się w dokumencie `Instrukcja_rejestracji_studenci.docx` dołączonym przez prowadzącego. Do aktualizacji istniejącego środowiska służy `PODMIANA_I_TEST.md` w ZIP-ie.
